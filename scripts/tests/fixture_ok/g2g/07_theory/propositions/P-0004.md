## Statement
Target theorem. Let every agent i have consumption x_i ≥ 0 (A-01) and reference level r_i > 0 (D-01), and suppose [SIG] U = V(ρ_i) with ρ_i = x_i / r_i (P-0001). Then for any change x_i → x_i' with x_i' / r_i > x_i / r_i, utility strictly rises: V(ρ_i') > V(ρ_i).

## Derivation
Step 1: by P-0002, ρ_i and ρ_i' are well defined and non-negative. Step 2: by P-0003, V'(ρ) > 0 for all ρ in the range. Step 3: a differentiable function with strictly positive derivative is strictly increasing (mean value theorem; cited as external literature: Rudin, Principles of Mathematical Analysis, 3rd ed., Thm 5.11, "if f'(x) > 0 for all x in (a, b) then f is monotonically increasing"). Step 4: ρ_i' > ρ_i therefore gives V(ρ_i') > V(ρ_i).

## Falsification surface
Observable pattern: agents whose consumption rises together with their peer group's (ρ_i constant) report no utility gain; a measured gain would falsify the [SIG] shape.
