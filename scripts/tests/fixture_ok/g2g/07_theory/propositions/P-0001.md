## Statement
For every agent i, the relative position ρ_i := x_i / r_i, where x_i ≥ 0 is agent i's consumption (A-01) and r_i > 0 is the reference level (D-01). ρ_i is dimensionless and takes values in [0, ∞).

## Derivation
Step 1: x_i ≥ 0 exists by A-01. Step 2: r_i > 0 exists by D-01, so the quotient x_i / r_i is defined. Step 3: the quotient is a composition of two registered symbols and introduces no new primitive; it is therefore a derived definition (3b.4).

## Falsification surface
Purely algebraic: failure of D-01 (no positive reference level) would void it.

## Notes
Intuition: position relative to one's circle, not absolute consumption.
