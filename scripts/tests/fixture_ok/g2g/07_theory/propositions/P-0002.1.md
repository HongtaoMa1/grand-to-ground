## Statement
For every agent i with consumption x_i ≥ 0 (A-01) and reference level r_i > 0 (D-01): ρ_i > 0 ⇔ x_i > 0, and ρ_i = 0 ⇔ x_i = 0.

## Derivation
Step 1: by P-0001, ρ_i = x_i / r_i with r_i > 0 (D-01). Step 2: for r_i > 0 the map x ↦ x / r_i is strictly increasing with value 0 at x = 0, so sign(ρ_i) = sign(x_i). Step 3: x_i ≥ 0 by A-01, so the two cases x_i > 0 and x_i = 0 exhaust the domain.

## Falsification surface
Failure of D-01 (r_i ≤ 0 admitted) would void it.

Revision of P-0002: adds the x_i = 0 case explicitly; re-passed the gate (V-0006).
