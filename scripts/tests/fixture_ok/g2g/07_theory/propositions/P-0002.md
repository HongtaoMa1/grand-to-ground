## Statement
For every agent i with consumption x_i ≥ 0 and reference level r_i > 0, ρ_i = x_i / r_i > 0 if and only if x_i > 0.

## Derivation
Step 1: by P-0001, ρ_i = x_i / r_i with r_i > 0 (D-01). Step 2: for r_i > 0, x_i / r_i > 0 iff x_i > 0, since division by a positive number preserves sign. Step 3: x_i ≥ 0 by A-01, so the only remaining case x_i = 0 gives ρ_i = 0.

## Falsification surface
Failure of D-01 (r_i ≤ 0 admitted) would void it.
